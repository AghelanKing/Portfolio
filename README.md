# Mohammad Mehdi Aghelan | Personal Portfolio

A modern, responsive personal portfolio website built with Next.js,
React, and Tailwind CSS to showcase my projects, technical skills, and
journey as a Frontend Developer.

## ✨ Features

- Modern dark theme with futuristic neon accents
- Responsive layout for desktop, tablet, and mobile
- Persian and English content
- Animated and interactive UI components
- Projects showcase
- About Me section
- Tech Stack visualization
- Personal journey timeline
- Contact section

## 🛠️ Tech Stack

- JavaScript
- React

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/AghelanKing/Portfolio.git
```

### Navigate to the project directory

```bash
cd Portfolio
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open <http://localhost:3000> in your browser.
